# mediascribe

TUI-first tool for transcribing, translating, and analyzing audio/video media.

```
pipx install mediascribe
mediascribe transcribe video.mp4 --lang ja --translate en
mediascribe translate subtitles.srt --target en
mediascribe config list
```

See [docs/SPEC.md](docs/SPEC.md) for full specification.  
Developers: see [docs/DEV.md](docs/DEV.md) for setup.
